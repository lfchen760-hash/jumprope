## 会话结果 v1（2026-11-10）

- `dart_core/lib/session_result.dart`：一次会话的不可变结果
  - `jumps`：逐跳 offsetMs（活动时间，不含暂停）
  - `activeMs` / `plannedMs` / `completed`
  - `valid` + `invalidReasons`：`unfinished` / `not_camera` / `out_of_frame` / `no_jumps`
- `SessionController`：
  - `counted` 时记 `frame.t`，按活动时间换算 offset；暂停段自动扣除
  - 支持自由跳（`durationSec <= 0`，不自动结束）和 `finishEarly()`
  - 结束时 `result` 可读；`SessionState` 增加 `activeMs` / `jumps`（只读视图）
  - 出框累计 > 3s 或 > 5% 判无效；完成度 < 90% 判「未完成」
- `SessionRecord.fromResult()`：核心结果 → 数据层记录（含档案快照）
- `SessionSaver`：结束后写库；拍照验证 App 已在 `finished` 时自动保存
- 测试：`dart_core/test/all_tests.dart` 新增 4 组会话结果用例（共 53 项通过）

## 成长日历 v1（2026-11-12）

- `lib/data/period.dart`（纯逻辑，可单测）：
  - `PeriodKind` 日/周/月/年；`PeriodRange` 闭区间（`YYYY-MM-DD`）
  - 周一起算；月/年边界、跨年周、`monthCells` 月历格子
  - 标题/区间文案；`percentChange` 环比，上期为 0 返回 null
- `lib/app/history/`：
  - `HistoryHeader`：记录标题 + 昵称/年级 + 年份选择
  - `PeriodTabs`：日 / 周 / 月 / 年
  - `PeriodSummaryCard`：总次数、活跃天、最好、连续、活跃日均；
    只有两个完整周期才显示环比，当前周期显示「本周期进行中」
  - `DayCard`：完成度圆环 + 目标 / 还差 / 训练次数
  - `WeekStrip`：周一到周日 7 根柱 + 当日次数，点某天进日视图
  - `MonthCalendar`：月历热力，颜色 = 当日完成度
    （0 / 1–49% / 50–99% / 100–149% / ≥150%），今天描边，未来不可点
  - `YearBars`：12 个月柱 + 月总量，点柱子进月视图
  - `PeriodBestCard`：周期内单次最好 + 2014 国标（仅 1 分钟、档案开了参考线）
  - `SessionList`：周期内明细，按日期分组，无效会话标「未计入」；最多 100 条
- 交互：默认月历；右上角「列表」切换到全部记录，再点「日历」切回；
  点月历某天 → 日视图；点年柱 → 月视图；
  `‹ ›` 按周期翻页，离开当前周期后出现「今天」按钮
- 删除：列表和周期明细右侧都有删除按钮，确认后调用
  `DataRepository.deleteSession(id)`；删完重新读库，首页/今日/连续/纪录同步刷新
- 测试：`test/period_test.dart`（周起点、闰月、跨年、月历格子、文案、环比、分档）

## 录像采集 v1（2026-11-12）

- 原生：CameraX 在预览 + ImageAnalysis 之外新增 `VideoCapture<Recorder>`；
  720p/30fps，带麦克风环境声；三路 UseCase 不支持时自动退回不录像。
- 手动开：计数页顶部摄像机按钮；开始前点开会在计数开始时自动录，
  计数中点开从当前时刻开始录；暂停会同步暂停录像，继续时恢复。
- 元数据：`session_videos`（DB v3）存原始文件路径、`start_offset_ms`、
  时长、宽高、旋转、是否有音频、文件大小；视频文件本身不入库。
  `start_offset_ms` 用来把会话的逐跳 offset 映射到视频时间轴，
  后续换特效只需要重跑导出，不用重录。
- 回放：结果页「查看原始录像」、记录列表的播放图标；使用 `video_player`。
- 保留：只留 3 天；App 启动时 `VideoStore.cleanup()` 删文件 + 元数据；
  删会话时一起删。导出到相册/分享是下一步（特效烧录）。
- 权限：新增 `RECORD_AUDIO`；首次开录像时请求，拒绝则不开录像。
- 未做：特效导出、保存相册/分享、录制中切摄像头（已禁用）。

## 计入规则调整（2026-11-12）

- 旧规则：完成度 < 90%（提前结束）或出框累计 > 5%/3s 的会话自动标「未计入」
- 新规则：**默认计入**；只有 0 跳、非相机两种自动判无效
- 提前结束/出框不再判无效；不想要的记录由用户手动删除
- `schemaVersion 1 → 2`：启动时自动把旧库中仅因这两条被标无效的会话
  改回计入（`valid=1` 并清空对应原因），迁移前备份 `.bak-v1`
- 新会话由 `SessionController` 直接按新规则生成；`Dart` 单元测试同步更新（53 项）
