## 会话结果 v1（2026-11-10）

- `dart_core/lib/session_result.dart`：一次会话的不可变结果
  - `jumps`：逐跳 offsetMs（活动时间，不含暂停）
  - `activeMs` / `plannedMs` / `completed`
  - `valid` + `invalidReasons`：`unfinished` / `not_camera` / `out_of_frame` / `no_jumps`
- `SessionController`：
  - `counted` 时记 `frame.t`，按活动时间换算 offset；暂停段自动扣除
  - 支持自由跳（`durationSec <= 0`，不自动结束）和 `finishEarly()`
  - 结束时 `result` 可读；`SessionState` 增加 `activeMs` / `jumps`（只读视图）
  - 出框累计 > 3s 或 > 5% 判无效；完成度 < 90% 判「未完成」
- `SessionRecord.fromResult()`：核心结果 → 数据层记录（含档案快照）
- `SessionSaver`：结束后写库；拍照验证 App 已在 `finished` 时自动保存
- 测试：`dart_core/test/all_tests.dart` 新增 4 组会话结果用例（共 51 项通过）

## 正式 UI v0（2026-11-10）

- 入口：`main.dart` → `lib/app/app.dart`（`JumpropeApp`），`CAMERA_TEST=true` 仍进最小相机页
- `lib/app/`：
  - `app_shell.dart`：底部三 Tab（首页 / 记录 / 我的）
  - `home_page.dart`：问候、目标环、今日/连续/昨天、60s/180s/自由跳、上次成绩
  - `result_page.dart`：次数表盘、用时/平均/中断、节奏柱、新纪录、无效原因
  - `history_page.dart`：按日期分组的会话列表，无效会话标灰
  - `profile_page.dart`：档案展示 + 「编辑」入口
  - `profile_form_page.dart`：首启引导 / 编辑共用表单，保存档案 + 目标
  - `theme.dart` / `ui.dart`：设计稿色板、渐变按钮、进度环、卡片
- 计数页：`lib/live_page.dart`（从原 `main.dart` 拆出，已按 `mock-live` 重做）
  - 顶部：关闭 / 计时胶囊 / 翻转 / 语音开关；下方状态胶囊（就位/出框/走动/弯腰）
  - 下半屏：96–104 大数字、当前次数、实时平均、橙粉进度条、圆形暂停
  - 关闭 × 弹「继续跳 / 结束并保存 / 放弃」，弹窗期间自动停表
  - 每跳一下「嘀」：普通 990Hz、整十次 1340Hz（和 Web `beep()` 同参数）；倒数/开始/结束也有提示音
  - 音效走原生 SoundPool（`res/raw/tick_*.wav`），不占 Flutter 音频通道，延迟低
  - 长按状态胶囊打开诊断；带时长进入后自动启动相机，到点落库 → 结果页
- 首启：`AppShell` 启动时读 `profile + settings.onboardingDone`，没档案先进引导
- 档案保存后 `dataVersion++`，首页问候/目标/参考线立即刷新
- 未做：真机确认音效（音量/音画同步）

## 成长日历 v1（2026-11-12）

- `lib/data/period.dart`（纯逻辑，可单测）：
  - `PeriodKind` 日/周/月/年；`PeriodRange` 闭区间（`YYYY-MM-DD`）
  - 周一起算；月/年边界、跨年周、`monthCells` 月历格子
  - 标题/区间文案；`percentChange` 环比，上期为 0 返回 null
- `lib/app/history/`：
  - `HistoryHeader`：记录标题 + 昵称/年级 + 年份选择
  - `PeriodTabs`：日 / 周 / 月 / 年
  - `PeriodSummaryCard`：总次数、活跃天、最好、连续、活跃日均；
    只有两个完整周期才显示环比，当前周期显示「本周期进行中」
  - `DayCard`：完成度圆环 + 目标 / 还差 / 训练次数
  - `WeekStrip`：周一到周日 7 根柱 + 当日次数，点某天进日视图
  - `MonthCalendar`：月历热力，颜色 = 当日完成度
    （0 / 1–49% / 50–99% / 100–149% / ≥150%），今天描边，未来不可点
  - `YearBars`：12 个月柱 + 月总量，点柱子进月视图
  - `PeriodBestCard`：周期内单次最好 + 2014 国标（仅 1 分钟、档案开了参考线）
  - `SessionList`：周期内明细，按日期分组，无效会话标「未计入」；最多 100 条
- 交互：点月历某天 → 日视图；点年柱 → 月视图；`‹ ›` 按周期翻页；
  离开当前周期后出现「今天」按钮
- 测试：`test/period_test.dart`（周起点、闰月、跨年、月历格子、文案、环比、分档）
