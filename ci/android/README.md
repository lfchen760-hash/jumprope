# DEV 签名（公开）

这个目录是**开发用**签名，给 CI 构建测试包用：

- `dev-upload-keystore.p12`：开发 keystore（别名 `upload`）
- `dev-keystore.properties`：密码/别名

## 为什么把它放进公开仓库

为了不改 GitHub Secrets，同时让每次 CI 构建用**同一把 key**，
这样 APK 可以覆盖升级，数据不会被卸载清掉。

## 必须知道的代价

- 仓库是公开的，**任何人都能拿到这把 key**，给同名包签名；
- 只能用于内部测试/开源开发版，**不要**用它上架、接账号/支付；
- 正式发布前，生成一把私有的 release key，替换 CI 签名；
  届时老用户需要卸载一次（或先做数据导出/导入）。

## 旧包

以前的 debug 包证书每次都不同，无法覆盖升级；测试机需要卸载一次。
从本 key 开始的后续版本，就可以正常覆盖升级、保留数据。
